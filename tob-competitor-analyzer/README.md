# tob-competitor-analyzer

ToB 竞品分析生成器 - 基于你的经验，自动生成专业的竞品分析报告

---

## 功能

输入竞品名称或官网，自动生成：
- 竞品基本信息（定位、融资、团队）
- 产品功能对比矩阵
- 定价策略分析
- 优劣势总结
- 应对策略建议

---

## 使用场景

- 售前阶段：快速了解客户提到的竞品
- 产品规划：分析市场格局
- 销售培训：统一竞品应对话术

---

## 快速开始

```bash
# 分析单个竞品
tob-competitor-analyzer --name "纷享销客" --industry "CRM"

# 对比多个竞品
tob-competitor-analyzer --names "Salesforce,HubSpot,纷享销客" --output report.md

# 从官网自动抓取
tob-competitor-analyzer --url "https://www.fxiaoke.com" --deep
```

---

## 参数说明

| 参数 | 说明 | 必填 |
|-----|------|------|
| `--name` | 竞品公司名称 | 是（或 --url） |
| `--url` | 竞品官网地址 | 是（或 --name） |
| `--industry` | 所属行业 | 否 |
| `--output` | 输出文件路径 | 否，默认 stdout |
| `--format` | 输出格式：md/json/html | 否，默认 md |
| `--deep` | 深度分析模式 | 否 |

---

## 示例输出

```markdown
# 纷享销客 竞品分析报告

## 基本信息
- **定位**: 中国领先的移动CRM服务商
- **成立时间**: 2011年
- **融资情况**: D+轮，累计融资超 5 亿美元
- **客户规模**: 服务超过 10000 家企业

## 产品功能矩阵

| 功能 | 纷享销客 | Salesforce | 我方 |
|-----|---------|-----------|-----|
| 客户管理 | ✅ | ✅ | ✅ |
| 移动办公 | ✅ 强 | ⚠️ 弱 | ✅ |
| 本土化 | ✅ 强 | ⚠️ 一般 | ✅ 强 |

## 定价策略
- 标准版: 180元/人/月
- 专业版: 360元/人/月
- 企业版: 按需报价

## 优劣势分析

**优势**
- 移动端体验好
- 本土化服务强
- 价格相对国际厂商低

**劣势**
- 大客户案例少
- PaaS能力弱
- 国际化支持差

## 应对策略
1. 强调大客户成功案例
2. 突出PaaS平台能力
3. 对比TCO（总拥有成本）
```
