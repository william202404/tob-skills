# tob-competitor-analyzer

深度竞品分析 Skill，占位中，尚未进入开发。

## 计划定位

面向售前、产品和销售培训场景，基于用户提供材料、公开信息或本地知识库，生成竞品分析报告。

计划输出：

- 竞品定位摘要
- 功能和场景对比
- 定价与 TCO 分析
- 优劣势与风险提示
- 应对策略建议
- 事实来源清单

## 边界

该 Skill 与 `tob-competitor-snip` 不同：

- `tob-competitor-snip`：即时话术卡，默认离线，不查实时竞品事实。
- `tob-competitor-analyzer`：深度报告，必须明确资料来源；如需要联网，需用户明确授权。

开发前必须先确认：

1. 是否允许联网查询公开资料。
2. 是否接入本地知识库。
3. 输出是否需要引用来源链接。
4. 如何区分公开事实、用户材料和经验判断。
